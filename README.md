# codex-tree

A CLI tool that generates a persistent knowledge tree for AI codebase comprehension.

## Problem

AI models waste significant tokens and time re-understanding codebases on every conversation or agent spawn. The same exploration happens over and over — reading files, discovering structure, learning patterns.

## Solution

codex-tree generates a `.codex-tree/` directory in your repository containing a structured, versioned knowledge tree that any AI model can load instantly:

- **AST/LSP layer** — deterministic, language-independent structural analysis (symbols, imports, exports, dependency graph)
- **AI intent layer** — design decisions, coding patterns, and rationale generated by Claude
- **Claude optimization layer** — progressive detail levels (L1/L2/L3) tuned for efficient context loading

## Key Properties

- **Model-independent** — any AI can consume the tree format
- **IDE-independent** — works with Claude Code, Cursor, VS Code, or any tool
- **Language-independent** — tree-sitter based parsing supports any language
- **CI-generated** — maintained automatically via GitHub Actions, not a developer responsibility
- **Independently versioned** — the tree has its own version, not tied to git commits

## Commands

```
codex-tree init      # Generate tree from scratch
codex-tree update    # Incremental delta update
codex-tree regen     # Full rebuild (new version)
codex-tree report    # Benchmarked token savings report
codex-tree check     # Staleness safety valve
```
